# Словарь терминов {data-kicker="ПРИЛОЖЕНИЕ Г"}

::: lead
Термины даны в том значении, в котором их использует книга. В скобках номер главы, где термин разобран подробно.
:::

| Термин | Значение |
|---|---|
| allowlist | список инструментов, разрешённых на текущей фазе задачи; всё остальное запрещено (9) |
| backoff | пауза перед повтором, растущая с каждой попыткой (6) |
| bootstrap | оценка разброса статистики повторными выборками с возвращением из тех же данных (13) |
| circuit breaker | выключатель, который после серии неудач временно перестаёт вызывать сервис (6) |
| contamination | утечка тестовых задач: попадание задач оценки в обучающие данные или примеры промпта (13) |
| doom loop | повтор действий без проверяемого продвижения к цели (4) |
| ECE | ожидаемая ошибка калибровки: средняя по бинам разница между уверенностью и долей верных (13) |
| guard | охранное условие перехода автомата, проверяемое по фактам (2) |
| HITL | human in the loop, участие человека в решениях агента (8) |
| jitter | случайный разброс паузы, чтобы клиенты не повторяли одновременно (6) |
| pass@k | доля задач, где успешна хотя бы одна из k попыток (1) |
| pass^k | доля задач, где успешны все k попыток (1) |
| replay | восстановление состояния задачи по журналу после перезапуска (7) |
| runtime | код вокруг модели: проверяет, исполняет, записывает (введение) |
| span | один участок трассы: имя, время, статус, атрибуты, родитель (11) |
| агент | языковая модель в цикле с инструментами и состоянием; модель предлагает, runtime исполняет (введение) |
| журнал событий | только дописываемый список завершённых шагов во внешнем хранилище (7) |
| интервал Уилсона | доверительный интервал для доли успеха, корректный у краёв (12) |
| каппа Коэна | согласие двух оценщиков за вычетом случайного совпадения (13) |
| ключ идемпотентности | идентификатор действия; повтор с тем же ключом не повторяет эффект (3) |
| конечный автомат | конечный набор состояний и явная таблица разрешённых переходов (2) |
| критический путь | самая длинная цепочка зависимых операций; задаёт время задачи (10) |
| неизвестный исход | ошибка записи, после которой нельзя сказать, случилось ли действие (6) |
| оптимистичная блокировка | запись проходит, только если версия данных не изменилась с чтения (10) |
| перцентиль p95 | наименьшее значение, которого не превышают 95% наблюдений (11) |
| песочница | набор ограничений runtime на инструменты, аргументы, сеть и секреты (9) |
| стоимость успешной задачи | средняя стоимость задачи, делённая на долю успеха (12) |
| тест Макнемара | проверка разницы двух версий по несогласным парам на одних задачах (13) |
| трасса | дерево спанов одного запуска агента (11) |
