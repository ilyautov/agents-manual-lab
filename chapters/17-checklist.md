# Чек-лист перед запуском агента {data-kicker="ПРИЛОЖЕНИЕ В"}

::: lead
Список собран из практических разделов глав. Пройдите его командой перед запуском и перед каждой крупной выкладкой. Пункт без ответа означает место, где агент сломается первым.
:::

## Цикл и состояние

| Пункт | Глава | Готово, если |
|---|---|---|
| Длина типичной задачи посчитана | 1 | известны медиана и p95 числа шагов по трассам |
| Детерминированное вынесено в код | 1 | даты, суммы, права считают инструменты |
| Состояния и переходы описаны таблицей | 2 | всё, чего нет в таблице, бросает ошибку |
| Завершение защищено guard | 2 | `done` проверяется по фактам runtime |
| Есть состояние «передано человеку» | 2 | у каждой остановки есть причина |

## Инструменты и планы

| Пункт | Глава | Готово, если |
|---|---|---|
| У каждого инструмента есть схема | 3 | лишние поля отклоняются, ошибки называют поле |
| Чтения и записи разделены | 3 | записи нельзя вызвать параллельно |
| Каждая запись несёт ключ идемпотентности | 3 | ключ выведен из заявки и действия |
| План проверяется до исполнения | 4 | порядок «проверка перед записью» проверяет код |
| Есть лимит повторяющихся неудач | 4 | агент сдаётся явно, а не до конца бюджета |
