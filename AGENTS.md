# AGENTS.md

Руководство для людей и ИИ-агентов, которые делают правки в этом репозитории. Полные правила книги в [WRITING.md](WRITING.md), процесс участия в [CONTRIBUTING.md](CONTRIBUTING.md).

## Что это за репозиторий

Книга «Инженерия агентов» (Markdown в `chapters/`) плюс лаборатория на TypeScript (Node 24, без зависимостей, без сети в тестах). Числа книги печатаются кодом в `build/numbers.json` и подставляются в главы при сборке PDF.

## Команды

```bash
npm test          # тесты; их число должно совпадать со счётчиком в README
npm run numbers   # build/numbers.json, детерминирован
npm run build     # PDF в out/, нужны pandoc + poppler-utils + Chrome (CHROME_PATH)
```

## Правила правок

1. Число в текст книги попадает только через `{{ключ}}` из `numbers.json`. Вписывать число руками нельзя.
2. Меняя код лаборатории, измени тесты: тесты проверяют числа книги.
3. После добавления тестов обновите счётчик в README и CHANGELOG.
4. Текст глав следует [WRITING.md](WRITING.md): без тире «—», без канцелярита, врезки с `data-title`, кавычки-ёлочки.
5. Сборка должна проходить: `npm test && npm run numbers && npm run build`.
6. Новые зависимости запрещены.
