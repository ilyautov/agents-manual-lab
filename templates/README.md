# Рабочие бланки к книге «Инженерия агентов»

Скопируйте нужный файл и заполняйте на собственном случае. Пустое поле означает «не проверено», а не «успех». Бланки повторяют структуру глав книги, поэтому их можно показывать аудиту без перевода.

| Бланк | Когда использовать | Глава книги |
| --- | --- | --- |
| [Карточка одобрения](approval-card.md) | Решение человека по необратимому действию: одна строка решения, факты, последствия | глава 8 |
| [Отчёт о передаче человеку](handoff-report.md) | Агент сдал задачу сотруднику: что сделано, что осталось, чем проверить | глава 8 |
| [Чек-лист перед запуском](launch-checklist.md) | Проверка агента до боя: автомат, бюджеты, повторы, песочница, оценка | глава 17 |

Не помещайте в бланки секреты и лишние персональные данные. Для каждого вывода сохраняйте ссылку на трассу запуска: вывод без трассы невозможно проверить.
