# Инженерия агентов

Бесплатная книга на русском о том, как построить LLM-агента, который не вернёт деньги дважды: состояния, инструменты, бюджеты, повторы, человек в контуре и честная оценка. С воспроизводимой лабораторией на TypeScript. Вторая книга серии «LLM на практике» после «Теории LLM и практики AI-лаборатории».

**Скачать PDF (75 страниц):** `out/Инженерия_агентов.pdf` после сборки · [Журнал изменений](CHANGELOG.md)

## Для кого

- **Инженерам**, которые делают агентов с инструментами и хотят, чтобы сбои, повторы и падения процесса не превращались в двойные списания.
- **Руководителям и аналитикам**, которые решают, где агенту нужен человек, как задать бюджет и как понять, что новая версия лучше старой. Главы с пометкой «для всех» читаются без кода.

Сквозной пример книги: агент поддержки интернет-магазина оформляет возврат денег. Заявки пяти видов: обычная, крупная (нужен человек), просроченная, с prompt injection в письме и с падением процесса посреди работы. Каждая глава разбирает, что в этой истории может пойти не так и какой механизм runtime это останавливает.

## Лаборатория

Нужен Node.js 24 (нативный запуск TypeScript). Внешних пакетов и сети не нужно, случайность детерминирована сидом (начальным значением генератора).

```bash
npm test               # 67 тестов: автомат, инструменты, повторы, журнал, песочница, оценка, числа книги
npm run numbers        # пересчитать build/numbers.json
npm run demo:agent     # сквозной агент на всех сценариях: одобрение, отказ, таймаут, авария, бюджет
npm run demo:machine   # переходы автомата и запрещённые переходы
npm run demo:retry     # backoff, jitter, толпа клиентов, circuit breaker
npm run demo:journal   # 120 сценариев падения: эффект ровно один с ключами
npm run demo:sandbox   # атаки и легальные вызовы против allowlist
npm run demo:eval      # Уилсон, Макнемар, bootstrap, каппа, ECE
```

Остальные демо: `demo:reliability`, `demo:tools`, `demo:planning`, `demo:budget`, `demo:approval`, `demo:dag`, `demo:trace`.

### Что здесь моделируется честно, а что нет

| Модуль | Что работает по-настоящему | Граница вывода |
|---|---|---|
| `machine.ts`, `tools.ts`, `sandbox.ts` | таблица переходов, схемы, allowlist и проверки аргументов | это код runtime, модель в нём не участвует |
| `retry.ts`, `journal.ts` | классы ошибок, паузы, выключатель, replay после падения | платёжный сервис симулирован в памяти |
| `agent.ts` | сквозной цикл агента со всеми механизмами | «модель» сценарная: она детерминированно предлагает шаги и один раз поддаётся инъекции |
| `eval.ts` | статистические методы на синтетических данных | частоты ошибок настоящих моделей не измерены |

## Сборка PDF

Нужны pandoc и Google Chrome (путь можно задать переменной `CHROME_PATH`). Команда `npm run build` пересчитывает числа, подставляет их в главы из `chapters/` и печатает PDF в `out/`. Настройки книги лежат в `book.json`, вёрстка в `build/style.css`.
